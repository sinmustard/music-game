# 연애재판 — RHYTHM COURT

프로젝트 세카이 스타일의 6키 리듬게임. HTML + 순수 자바스크립트(라이브러리 없음)로 만들어졌습니다.

`index.html`을 더블클릭하면 바로 실행됩니다. (빌드·서버 불필요)

---

## ⚖️ 음원에 대해

**곡 파일은 포함되어 있지 않습니다.** 恋愛裁判(연애재판)은 저작물이므로,
본인이 정식으로 구매·소장 중인 음원 파일을 타이틀 화면에서 직접 불러와 주세요.

* 음원을 불러오면 → 그 파일에 맞춰 플레이
* 음원이 없으면 → **메트로놈 모드** (BPM 150 클릭음)로 채보만 플레이

지원 형식: mp3 / ogg / wav / m4a (브라우저가 디코딩 가능한 것)

## 📊 난이도

프세카 기준보다 한 단계 위로 맞췄습니다. 판정 폭도 더 좁습니다.

| 난이도 | Lv | 노트 | 평균 NPS | 최대 NPS |
|---|---|---|---|---|
| NORMAL | 14 | 787 | 3.9 | 9 |
| HARD | 20 | 1,022 | 5.0 | 11 |
| EXPERT | 26 | 1,196 | 5.9 | 14 |
| MASTER | 31 | 1,413 | 6.9 | 16 |
| **APPEND** | **35** | **1,586** | **7.8** | **17** |

**판정 폭** — PERFECT ±42ms / GREAT ±78ms / GOOD ±112ms / BAD ±155ms
(프세카는 PERFECT가 대략 ±67ms이므로 약 1.6배 빡빡합니다.)

콤보는 PERFECT·GREAT에서만 유지됩니다. 만점은 1,000,000점
(노트 950,000 + 최대 콤보 보너스 50,000).

## 🔍 오디오 자동 채보

음원을 불러온 뒤 **"불러온 음원 분석해서 채보 생성"** 을 누르면,
실제 음원을 분석해 그 곡에 맞는 채보를 만들어 줍니다.

1. STFT(1024pt) → 밴드별 **스펙트럴 플럭스**로 타격음(온셋) 검출
2. 온셋 포락선 **자기상관**으로 BPM 추정 (100~210 BPM)
3. 박자 **위상(offset)** 탐색 → 16분 격자에 스냅
4. 음색 밝기(스펙트럴 중심)로 레인 배치, 공백 구간엔 홀드/슬라이드,
   고역이 강한 타점엔 플릭 배치

합성 드럼 트랙으로 검증했을 때 BPM은 정확히, 위상은 **오차 2ms**로 잡혔습니다.
내장 채보와 달리 곡의 실제 리듬을 따라가므로 싱크가 맞습니다.

> 곡이 도중에 템포를 바꾸면 정확도가 떨어집니다. 그럴 땐 내장 채보를 쓰세요.

## 🛠 싱크가 안 맞을 때

브라우저·헤드폰마다 출력 지연이 다릅니다.
**판정 오프셋** 슬라이더로 맞추세요 (플레이 중 <kbd>Esc</kbd> 로도 조절 가능).

* 노트가 **먼저** 도착하는 느낌 → 오프셋을 **+** 방향으로
* 노트가 **늦게** 오는 느낌 → **−** 방향으로

FAST / LATE 표시를 보면서 한쪽으로 치우치면 그만큼 밀어 주면 됩니다.

## 📁 구조

```
index.html          화면 구성
css/style.css       스타일
js/util.js          난수·보간·FFT 등 공용 유틸
js/chart.js         내장 채보 생성기 + 난이도 파생 + 충돌 정리
js/analyzer.js      오디오 온셋 검출 → 자동 채보
js/engine.js        판정 / 점수 / 게이지
js/render.js        캔버스 렌더러 (원근 레인)
js/input.js         키보드 / 터치 입력
js/main.js          화면 전환 · 오디오 · 게임 루프
```

곡 시간은 Web Audio의 `AudioContext.currentTime` 기준으로 계산하므로
`requestAnimationFrame` 이 끊겨도 판정이 밀리지 않습니다.

### 채보 검증

전 난이도에 대해 "완벽한 플레이어" 시뮬레이션을 돌려
**ALL PERFECT / 1,000,000점**이 나오는 것을 확인했습니다.
즉 물리적으로 칠 수 없는 배치(슬라이드가 지나가는 레인에 겹친 탭 등)는 없습니다.
